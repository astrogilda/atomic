Atomic can already hand reviewers a native PROV projection, but a DSSE-consuming reviewer has no portable signed export or pinned-key reader. This adds optional `dsse-export` support to `provenance show` and `trace --json`, plus an offline `verify-dsse` command that emits only the exact authenticated payload bytes.

The versioned container declares exporter-only coverage. It preserves existing projections and any native Data Integrity proofs, and reuses Atomic Ed25519 keys through DSSE traits with its default backend disabled. Ordinary output and native hashes/signatures stay unchanged. Export signatures do not establish original authorship, authorized action, claim truth, complete capture or verification of referenced primaries.
